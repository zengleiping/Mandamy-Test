⚙️ 課堂環境與模式設定

「右側」只對注音有效（拼音一律在字的上方）。想改某個字的讀音：點那個字的注音／拼音，聲調可以直接打數字——1～4＝一～四聲、0＝輕聲（例如 ni3 會自動變成 nǐ，ㄋㄧ3 會變成 ㄋㄧˇ）。

用「文字」工具在小白板上打字時，字的正上方要不要自動加拼音或注音——第一次用文字工具時會問一次，之後都可以回這裡改。

小白板「鎖定作答」時，學生如果還是試圖畫圖或按按鈕，會跳出提醒彈窗——這裡選要顯示哪些語言（可複選），預設中文＋英文。

✏️ 打字要加註音嗎？

用「文字」工具打字時，字的正上方要自動加拼音還是注音？之後可以到「⚙️ 設定」裡隨時改。

📴 偵測到離線期間的修改 Offline Changes Found

這台裝置上有一份離線時編輯的課程，跟雲端上的不一樣。請選擇要用哪一份——沒選的那份不會消失，會保留在「🕘 版本記錄」，之後隨時可以還原。
The copy edited offline on this device differs from the cloud copy. Pick which one to keep — the other stays in Version History so you can restore it any time.

🕘 版本記錄 Version History

這些版本存在這台裝置的瀏覽器裡（不會上傳雲端）。自動存檔約每 5 分鐘一份，保留 30 天（越舊的越稀疏）；📌 釘選的版本永久保留。還原前會自動再存一份「還原前的版本」，所以按錯也能回來。
Saved on this device only. Auto-saved about every 5 min and kept for 30 days; pinned versions are kept forever.
